# 2048 合成花园

抖音小游戏 v0.1 原型：竖屏 Canvas 版 2048 一格推进玩法，包含核心合成逻辑、滑动操作、分数、最高分、本地存档、撤回和重新开始。

## 在抖音开发者工具中运行

1. 打开抖音开发者工具。
2. 导入当前目录。
3. 将 `project.config.json` 里的 `appid` 替换为你的小游戏 AppID。
4. 编译运行。

## 在浏览器中预览

直接打开 `index.html` 即可快速预览。浏览器预览提供了 `tt` API 的降级实现，方便调试基础玩法。

## 当前版本范围

- 4x4 一格推进版 2048 玩法。
- 每次滑动时，棋子最多只沿方向前进一格；只有紧挨着的相同值会合并。
- 拖动时棋子会跟手预览，超过临界点才提交移动；没超过则回弹且不会合并。
- 下一个出现的值会提前显示，并根据当前局势动态决定概率。
- 触控滑动、鼠标拖动、键盘方向键。
- 分数与最高分。
- 自动本地存档。
- 撤回一步。
- 游戏结束检测。

广告、每日任务、图鉴和道具系统会在后续版本接入。
